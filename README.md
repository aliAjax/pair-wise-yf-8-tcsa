# 胶片接片工艺复核台

一个纯前端本地应用，在原有胶片分镜条核对能力（片段录入、拖拽排序、时长统计、颜色偏移筛选、破损提醒、清单导出）之上，补齐接片工艺复核流程。直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 接片规则

- 只有**放映顺序中相邻**、且**片基材质相同**的两个片段可以建立接片。
- 只接受**胶带接片**；登记时必须填写**摩擦测试人**与**接缝长度**，并记录摩擦测试结论。
- 接缝长度**至多 8 格**。缺项、长度超过 8 格、或摩擦测试不合格时**整次拒绝**：不写入记录、不改顺序，既有接片原样保留，表单内显示拒绝原因。
- 接片通过后如摩擦测试出现异常，可上报把该接片**转为待复核**，并在接片上**留下历史**（登记记录与异常记录都可追溯）。
- 拖拽改序或删除片段后，既有接片记录**原样保留**；不再相邻或片段缺失的接片会单列并在核对栏提示。
- 片段、顺序与全部接片记录都保存在浏览器 localStorage。

## 统计、提示与导出

- 顶部统计：总时长、片段数、接片数、待复核接片数、破损片段数。
- 右侧核对栏：待复核接片、错位/缺失接片、颜色偏移与破损片段。
- 导出文本追加「接片工艺记录」：每段接片的片段对、方式、片基材质、接缝长度、摩擦测试人、当前状态（含错位说明）以及完整历史。

## 文件划分

不新增页面与第三方依赖，业务代码按职责拆为三个文件：

| 文件 | 职责 |
| --- | --- |
| `rules.js` | 规则判定：相邻/同材质/胶带方式校验、缺项与 8 格上限、测试合格判定、异常转待复核、接缝位置检测 |
| `store.js` | 持久化：localStorage 读写、片段与接片记录的状态管理、拒绝时不改状态 |
| `render.js` | 渲染：统计、片段与接缝列表、待复核/错位/破损提示、导出文本 |
| `app.js` | 入口与事件编排（表单、拖拽、按钮），不含业务规则 |

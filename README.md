# 胶片接片工艺复核台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序，并在相邻片段之间复核胶带接片工艺：

- 只有放映顺序中相邻、且片基材质相同的两个片段，采用胶带接片时才能建立接缝；
- 建立时必须登记摩擦测试人和接缝长度（正整数，最长八格）及摩擦测试结果；
- 缺项、接缝长度超过八格或摩擦测试不合格时整次拒绝，不写入记录，顺序与既有接片原样保留；
- 接片通过后若复测出现摩擦测试异常，该接片转为“待复核”，全部状态变化写入历史，可在复核台确认复核通过；
- 统计、提示与导出（片段顺序 + 接片记录 + 历史）随状态更新，数据保存在浏览器 localStorage。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。无任何外部依赖。

文件分工：

- `rules.js`：接片规则判定（相邻、同材质、胶带接片、缺项/八格/测试判定、状态流转与历史）；
- `store.js`：localStorage 持久化、默认数据与旧核对台数据迁移；
- `render.js`：统计、片段与接缝列表、复核台、提示和导出文本的渲染；
- `app.js`：事件编排与流程串联。
